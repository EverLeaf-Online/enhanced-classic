# EverLeaf native client third-party notices

EverLeaf's native client contains code and ideas derived from earlier MapleStory v83 community projects and reference implementations. Those upstream names are retained here only for attribution/provenance, not as EverLeaf branding.

## Ezorsia / MapleEzorsia lineage

The original native hook layer was derived from the historical Ezorsia v2 source tree. Its upstream GPL license is preserved in `third_party/UPSTREAM_LICENSE.txt` and remains applicable to derivative code where required.

## Microsoft Detours

The repository includes prebuilt Detours libraries used by the Win32 hook layer. Microsoft Detours remains subject to its upstream license terms.

## Kaentake and other v83 references

Kaentake and other public v83 client projects are used as behavioral/reference material for resolution, widescreen, UI, and compatibility work. Code should only be copied when its license permits; otherwise EverLeaf reimplements the verified behavior against the pinned v83 client.
