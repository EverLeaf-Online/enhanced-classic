# EverLeaf Documentation Archive

This directory preserves historical evidence, superseded plans, donor/reverse-engineering research, and upstream reference material that remains useful but must not be mistaken for current EverLeaf production documentation.

## Folders

- `audits/` — dated/static/live audit reports and snapshots.
- `client-research/` — selector, donor, copycat/Yuna, and native-client reverse-engineering evidence.
- `content-research/` — superseded Future Henesys/Empress candidate/import planning.
- `project-history/` — early project plans, obsolete branch policy, feature-consolidation history, and integration-era notes.
- `merged-source/` — original documents whose maintained material was consolidated into the new topic guides.
- `upstream/` — inherited HeavenMS/Cosmic reference notes and non-document artifacts formerly mixed into `docs/`.

## Rule

Archive files are evidence only. They may contain old branch names, old release SHAs, old WZ counts, old IP/topology assumptions, incomplete feature lists, or plans that have since shipped. Do not cite an archive file as current status without reconciling it against `../EVERLEAF_MASTER_CHECKLIST.md` and the maintained topic guides.
